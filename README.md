# Amak Asantewaaba Ventures — File & Photo Portal

A genuine upload-enabled website for Amak Asantewaaba Ventures.

## Run locally
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000`.

Uploaded files are stored in `public/uploads`.

## Before public deployment
For a production website, add authentication/admin access, HTTPS, cloud/object storage (such as S3-compatible storage), malware scanning, backups, rate limiting, and database-backed file metadata. The current version is a functional starter portal and stores files on the server filesystem.
